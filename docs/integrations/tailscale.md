# Tailscale local-status compatibility

M8 uses only the host's installed `/usr/bin/tailscale status --json` command. The ordinary, unprivileged collector runs it every 30 seconds when `"tailscale": true` is set in the root-owned collector configuration. It has a five-second deadline, 2 MiB combined output cap, fixed arguments, and no shell. It does not use a cloud admin token, ping peers, upload diagnostics, or change Tailscale settings. The app only reads the sanitized host snapshot.

The projection includes the local backend state, version, self hostname/Tailscale IPs and at most 250 locally known peers with stable ID, hostname, up to two Tailscale IPs, reported `Online`, and optional `LastSeen`. Last-seen is unknown when absent or zero; it is not inferred from traffic. Peer keys, user profiles, endpoints, tags, routes and raw CLI output are discarded before the snapshot is written. A capped or malformed list is marked partial; it cannot erase a previously complete cached inventory. An offline peer is informational by default. Only local client failure can affect the configured Tailscale summary.

This is not a complete tailnet inventory: ACLs and local network-map state affect which peers this client knows. Reported online describes control-plane status, not whether any service on the peer is reachable. These semantics follow the [Tailscale status types](https://github.com/tailscale/tailscale/blob/main/ipn/ipnstate/ipnstate.go) and [CLI reference](https://tailscale.com/docs/reference/tailscale-cli), but the installed client's version and permissions require an Ubuntu live check. Synthetic fixture coverage does not establish installed-version compatibility.

Before enabling, run `sudo -u labdeck-collector /usr/bin/tailscale status --json` locally and review the output privately for permissions and unexpected content. Do not paste raw output into issues or fixtures. If denied, leave the module off until a minimal access arrangement is reviewed; do not grant broad Tailscale operator controls. After enabling, run `LABDECK_LIVE_TEST=true LABDECK_HOST_SNAPSHOT_PATH=/var/lib/labdeck-collector/public/system/snapshot.json npm run test:live -- --provider=tailscale` on Ubuntu. This checker reads the sanitized snapshot only. Compare the peer counts/states locally, including online, offline, missing LastSeen, and a known peer omitted by policy if available; document the installed version and permission matrix.
